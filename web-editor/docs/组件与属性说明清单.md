### 组件化约定（改组件不用动框架）

| 约定 | 说明 |
|---|---|
| 一个组件一个文件 | `src/registry/components/{common,document,ppt,web}/*.tsx`，导出 `xxxComponent: ComponentDefinition` |
| 注册靠目录自动发现 | `index.ts` 用 `import.meta.glob` 扫描；**加/删组件不改框架文件**（文件名以 `_` 开头则忽略） |
| 组件定义字段 | `type / label / category / supportedModes / icon / description / isContainer / defaultProps / defaultFrame / propSchema / render` |
| 渲染契约 | `render(props, ctx)` 返回真实最终外观（真实 `<h1>`/`<table>`/`<button>`…），编辑器只在外层套选中/悬停外壳 |
| 模式过滤 | `supportedModes`，面板与画布按当前模式过滤 |
| 通用属性 | 注册表统一给**所有组件**补 `上边距(mm)`/`下边距(mm)`（属性表里标注"通用属性"） |
| 容器 | `isContainer: true` 可嵌套子组件（children 注入容器元素内部） |
| 外部组件（热加载） | `public/组件/*.js` 调 `window.EditorKit.register(...)`，改完点「重载外部组件」，不用构建 |
| 单个组件出错不拖垮整体 | 每个节点外套节点级错误边界，render 抛错只把该节点降级成红框提示 |

## 二、属性编辑器总说明

| 项 | 规则 |
|---|---|
| 排布 | 两列紧凑列表：左列固定宽属性名、右列控件，一行一个属性 |
| 属性名 | 只显示主名（`列宽（如 20,50,30；纯数字按 %，也可写 35mm）` → 显示 `列宽`）；带虚线下划线表示"可悬停看说明" |
| 说明 | **默认全部隐藏**，鼠标悬停属性名弹气泡（自研 Tooltip，非原生 title） |
| 整行式控件 | `textarea / richtext / spacing / edge / frame / children / cells / tableSize` —— 标签在上、控件独占整行 |
| 分组顺序 | 单元格 → 表格 → 内容 → 排版 → 外观 → 尺寸 → 布局 → 高级 |
| 默认展开 | **只展开第一个分组**（表格类即「单元格」组）；画布上选中单元格时「单元格」组强制展开 |
| 分组说明 | 分组标题悬停弹气泡，写明该组是"整表"还是"选中的单元格" |
| 未选中组件 | 文档模式显示「页面属性」，Web 模式显示「画布属性」 |
| 编辑器态 vs 文档数据 | 选中了哪些单元格、悬停/选中态属**编辑器态**（不导出、不打印）；组件属性（含 `cellStyles`）属**文档数据** |

- 一句话说明：真实 table 元素：全框线 / 三线表 / 横线表，可设表头、斑马纹、对齐
- 功能属性共 **29** 项

**选中它之后，属性编辑器的状态**

- **面板分组（3 个，按此顺序）**：**单元格 1（默认展开）** ｜ 表格 24（折叠） ｜ 尺寸 4（折叠）
- **排版**：单行式 24 项（左列属性名 + 右列控件）｜整行式 5 项（tableSort、tableSize、tableHtml、tableRowHeights、cells，标签在上、控件独占整行）
- **顶部固定区**：组件名 + `table` 徽标、组件 ID（可一键复制）、「过滤属性…」输入框
- **Web 模式额外**：选中时面板顶部多一块「位置与尺寸（px）」。x / y / w / h 四个数值输入
- **用到的控件**：`switch`、`tableSort`、`text`、`number`、`align`、`unit`、`tableSize`、`tableHtml`、`select`、`color`、`slider`、`tableRowHeights`、`cells`

**它的功能属性**

**「单元格」组**（1 项 · 默认展开）

> 分组气泡说明：只作用于画布上选中的单元格（点选/拖选一片）：**文字内容也在这里改**（表格不再有整块「数据」属性），没被覆盖的格式沿用「表格」组的默认值。

| 属性（面板显示名） | key | 控件 | 排版 | 默认值 | 说明 / 取值 |
|---|---|---|---|---|---|
| 单元格格式 | `cellStyles` | `cells` | 整行式 | `{}` | 先在画布上点选单元格，可拖选一片；没覆盖的项沿用「表格」组的默认值 |

**「表格」组**（24 项 · 默认折叠）

> 分组气泡说明：整张表格的属性。上面「单元格」组里针对个别格子做的设置会覆盖这里的默认值。

| 属性（面板显示名） | key | 控件 | 排版 | 默认值 | 说明 / 取值 |
|---|---|---|---|---|---|
| 首行为表头 | `headerRow` | `switch` | 单行式 | `true` | — |
| 首列为表头 | `headerCol` | `switch` | 单行式 | `false` | 第一列作为行标题：加粗 + 表头底色 |
| 排序 | `sortBy` | `tableSort` | 整行式 | `-1` | 按列 A/B/C…；只影响**显示顺序**，原始行序与单元格格式都不动 |
| 排序方向 | `sortDir` | `text` | 单行式 | `asc` | 按条件显示 |
| 冻结首行 | `stickyHeader` | `switch` | 单行式 | `false` | Web 模式：表头滚动时钉在顶部；按条件显示 |
| 冻结时表格最大高度 | `stickyHeight` | `number` | 单行式 | `360` | px，超出才滚动；范围 80~2000；按条件显示 |
| 表题 | `caption` | `text` | 单行式 | （空） | 显示在表格上方 |
| 表题对齐 | `captionAlign` | `align` | 单行式 | `left` | — |
| 表题字号 | `captionSize` | `unit` | 单行式 | `10.5` | 单位 pt；范围 6~24 |
| 行 / 列数量 | `tableSize` | `tableSize` | 整行式 | — | 含表头行；行数/列数在失焦或回车时生效；插入/删除会同步平移单元格格式与列宽，可 Ctrl+Z 撤销；先在画布上点一个单元格 |
| HTML 源码 | `html` | `tableHtml` | 整行式 | （空） | 粘贴 <table>…</table> 点「导入 HTML」即可变成表格；也能把当前表格生成 HTML |
| 线条风格 | `variant` | `select` | 单行式 | `normal` | 可选：全框线（普通表格） / 三线表 / 横线表（无竖线） |
| 边框宽 | `borderWidth` | `number` | 单行式 | `1` | 范围 0~6 |
| 边框色 | `borderColor` | `color` | 单行式 | `#c9d6e2` | — |
| 表头底色 | `headerBackground` | `color` | 单行式 | `#e8f1f9` | — |
| 三线表线条色 | `headerColor` | `color` | 单行式 | `#1f2329` | — |
| 表宽 % | `width` | `slider` | 单行式 | `100` | 范围 20~100 |
| 列宽 | `colWidths` | `text` | 单行式 | （空） | 如 20,50,30；纯数字按 %，也可写 35mm |
| 行高 | `rowHeight` | `text` | 单行式 | （空） | **整表默认**，如 9；纯数字按 mm；单行高度用画布拖行边界或下面那条 |
| 按行行高 | `rowHeights` | `tableRowHeights` | 整行式 | `{}` | 画布上拖某一行边界只改那一行；这里可逐条清除 |
| 内边距 | `cellPadding` | `number` | 单行式 | `6` | 默认值；范围 0~24 |
| 字号 | `fontSize` | `unit` | 单行式 | `10.5` | 默认值；单位 pt；范围 6~24 |
| 单元格对齐 | `cellAlign` | `align` | 单行式 | `left` | 默认值 |
| 斑马纹 | `stripe` | `switch` | 单行式 | `true` | 仅全框线 |

**「尺寸」组**（4 项 · 默认折叠）

> 分组气泡说明：宽高与上下边距。

| 属性（面板显示名） | key | 控件 | 排版 | 默认值 | 说明 / 取值 |
|---|---|---|---|---|---|
| 上边距 | `marginTop` | `unit` | 单行式 | `0` | mm；单位 mm；范围 0~100；通用属性（注册表统一补） |
| 下边距 | `marginBottom` | `unit` | 单行式 | `0` | mm；单位 mm；范围 0~100；通用属性（注册表统一补） |
| 左边距 | `marginLeft` | `unit` | 单行式 | `0` | mm；单位 mm；范围 0~100 |
| 右边距 | `marginRight` | `unit` | 单行式 | `0` | mm；单位 mm；范围 0~100 |

## 三、维护指引

| 想做什么 | 怎么做 |
|---|---|
| 加一个内置组件 | 在对应分类目录新建 `.tsx`，导出 `ComponentDefinition`；**不用改框架文件** |
| 加一个外部组件（不构建） | `public/组件/` 放 `.js`，调 `window.EditorKit.register(...)`，点「重载外部组件」 |
| 加一种属性控件 | `property-controls/index.tsx` 加 `case` 并加进 `IMPLEMENTED_CONTROLS`，schema 即可用 |
| 改分组顺序 / 默认展开 / 分组说明 | `components/panels/groupStrategy.ts` 的 `GROUP_ORDER`（默认展开=排序后的第一个分组）/ `GROUP_HINTS` |
| 重新生成本清单 | 菜单「帮助 → 导出组件与属性说明清单」，或访问 `?spec=1`（写到运行目录 `docs/`） |

> 自检（`?check=1`）核对：分类只用约定分类且每类都有组件、每个组件都有自己的配置属性、
> 每个组件 schema 里的控件都已实现、注册表由目录自动发现、属性面板无溢出与属性名折行。

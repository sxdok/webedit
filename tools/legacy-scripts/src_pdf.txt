产品概述
海康机器人工控机深耕视觉领域，支持配套面阵相机、线阵相机、智能相机、读码器、3D 立体相机等工业相机，
兼容千兆/ 万兆网口、USB3.0 口、Camera Link 接口、CoaxPress 接口、XoFLink 接口等各类图像采集卡，
同时支持同时支持VM 算法开发平台、Robotpilot 机器人视觉引导平台等视觉相关软件。工控机作为视觉产品的
硬件中枢和软件载体，与其他视觉产品共同构建完整的机器视觉解决方案，更好的服务于机器视觉行业应用。
可靠性
能在粉尘、烟雾、高/ 低温、潮湿、震动、腐蚀环境下稳定运行，MTTF（Mean Time to Failure）在
10 万小时以上，而普通计算机的MTTF 仅为10000 ～15000 小时。
扩展性
具有强大的输入输出功能，含有LAN，PCI-e，USB3.0 等丰富接口，能与各种外设、机器视觉相机、
视频监控系统等相连，适用各种场景应用。
实时性
对工业生产过程进行实时在线检测与控制，对工作状况的变化给予快速响应，及时进行采集和输出调节
(WatchDog Timer 功能)，保证系统的正常运行。

CPU
CPU 它相当于人类的大脑，是信息处理、程序运行的最终执行单元，其位于设
备内部主板上的特殊插槽中。CPU 与主板是相互搭配的，不同的主板所支持的
CPU 型号也不相同。CPU 的主要参数有：主频，缓存，总线结构，核心线程数。
CPU 的运算速度也就越快。
核心数：核心数为一个CPU 拥有的运算单元数量，例如8 核，即一个CPU 有8 个核心，拥有8 个独立的运算单元。
线程数：是一种逻辑的概念，简单地说，就是模拟出的CPU 核心数。比如，可以通过一个CPU 核心数模拟出2 线程
的CPU，也就是说，这个单核心的CPU 被模拟成了一个类似双核心CPU 的功能。 
CPU 命名后缀含义：部分Intel CPU 在命名时会加入K/F/M/U 这类后缀，其主要的含义分别是： 
K: 可以超频版本 
F: 不具备核显版本 
M: 双核移动版本 
U: 超低功耗版本
主频: CPU 进行运算时的工作频率，又称为CPU 内部的时钟频率。一般来说，主频越高，
内存（RAM）
内存在整机里的作用很关键。第一个作用是用来暂存处理器（CPU）的运算数据。第二个作用是
和固态硬盘、机械硬盘等外部存储器交换数据。内存的主要参数有：容量、频率和内存时序。
容量：内存空间大小，可以放多少个 G 的数据，理论上来说越大越好。
时序：内存在不同工作环节当中的延迟时间，内存时序数值越低，工作延迟越短。

硬盘
硬盘是工控机中重要的存储器之一。计算机需要正常运行所需的大部分软件都存储在硬盘上。根据架构的不同目前硬
盘被分为传统的机械硬盘（HDD）和固态硬盘（SSD）两类。
固态硬盘（SSD）
以固态电子存储芯片阵列制成的硬盘，主要由主控单元和存储列阵组成。目前主流的固
态硬盘种类繁多，主要通过接口类型和传输协议进行区别：
按照传输协议可以分为SATA 与Nvme 两类, 按照接口类型可分为SATA 与M.2 两类。
SATA 协议是目前所应用最广泛的传输协议，传输速度快，执行效率高，还支持热插拔。
NVMe 协议是专门为闪存产品开发的传输协议，能充分发挥SSD 的产品性能同时降
低延迟，是M.2 接口的固态硬盘首选协议。
机械硬盘（HDD）
是集精密机械、微电子电路、电磁转换为一体的电脑存储设备，为电脑主要的存储媒介
之一。由一个或者多个铝制或者玻璃制成的磁性碟片、磁头、转轴、控制电机、磁头控
制器、数据转换器，接口和缓存等几个部分组成。
机械硬盘按照适用的客户群体分为企业级和监控级：
监控级硬盘：一般用于流媒体播放和视频监控领域，适合24*7 的工作强度。但总体可
靠性较企业级硬盘低。
企业级硬盘：它的可靠性最高，有更强大的纠错率，综合考虑企业级硬盘的评分最高，最适合存放重要数据。
RAID

现比单块磁盘更好的存储性能和更高的可靠性。
根据组合方式的不同，在工控机的使用场景下主要的RAID 级别有RAID 0/1/5/10。

RS-422:RS-422 由RS-232 发展而来，它改进了RS-232 通信距离短( 最大传输距离15m)、速率低的缺点。
RS-422 定义了一种单相，平衡通信接口，将传输速率提高到10Mbps，最大传输距离延长到1200 米。
RS-485:RS-485 标准相比于RS-422，增加了多点、双向通信能力。在多站互连时可节省信号线，便于高速、
远距离传送。
串口：在串行通讯时，要求通讯双方都采用一个标准接口，使不同的设备可以方便地
连接起来进行通讯的物理接口形式( 硬件)。常见的串口协议有RS-232、RS-422、
RS-485 等。
SATA 接口:SATA 是主流硬盘接口之一。SATA 接口很容易辨别，其具有十分鲜明的
L 型，SATA 接口结构简单，支持热插拔，传输速度快，执行效率高。用于连接2.5 英寸
固态硬盘和3.5 英寸机械硬盘。
PCIe 接口：是一种高速串行计算机扩展总线标准，随着技术的发展，标准已更新到第五
代技术PCIe5.0。PCIe 可拓展性强，可以支持扩展显卡、网卡、视频采集卡等。PCIe
接口的带宽也与其对应的通道数有关，且通道数越多传输速度越快，插槽长度越长。
PCIe 按长度划分为PCIe X1、PCIe X2、PCIe X4、PCIe X8、PCIe X16。相应的

PCI 接口: 支持PCI（Peripheral Component Interconnect）总线协议的插槽。
PCI 接口用于连接符合 PCI 总线标准的银屏，网络等设备。PCI 槽在主板上，一般为
乳白色的插槽。工控机中PCI 接口主要接运动控制卡。
内存插槽: 安装内存条的槽位。主板所支持的内存种类和容量都由内存插槽来决定的。
内存插槽通常最少有两个，最多能达到8 个。配置内存双通道必须将内存插在相同颜色
的内存插槽中。

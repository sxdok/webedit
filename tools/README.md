# tools —— 针对两个应用写的工具与测试

## check_print.py（web-editor 打印验证）

用途：把 web-editor 的打印结果导出成 PDF，并做**客观断言**，避免"看起来没问题"。

```powershell
# 先启动服务（另开一个窗口）
D:\Python313\python.exe "E:\可视化编辑器\web-editor\启动编辑器.py" -p 5179 -q
# 再用无头 Edge 打印并断言（脚本内已包含落盘与解析）
D:\Python313\python.exe "E:\可视化编辑器\tools\check_print.py"
```

它检查：页数、页尺寸（应为当前纸张，如 A4 595.0×841.9pt）、内容包围盒（左/上应落在文档页边距上）、
是否混入编辑器界面元素、是否出现空白页、柱状图等**背景色图元**是否真的输出
（Chrome 默认不打印背景色，需要 `print-color-adjust: exact`）。

⚠ 注意：无头 Edge 打印**默认留约 1cm 边距**，而纸张是 297mm —— 因此 CLI 打印会多出空白页，
这是打印方式导致的，不是编辑器缺陷。真实浏览器打印请按应用内提示设置：
**纸张 A4、缩放 100%、边距「无/默认」、勾选「背景图形」**。

## 应用自带的自检（推荐优先用）

- **web-editor**：`http://127.0.0.1:5179/?check=1` —— 50 条断言，覆盖数据层、渲染、真实 PointerEvent 交互、
  分页与分页符、页眉页脚（页面属性）、缩放唯一性、打印外壳、导出（HTML/Word/React）、组件热加载、验收项。
  报告在页面左下角；**打印该页可得到完整报告**（打印样式里已展开列表，不会被裁掉）。
- **A4 编辑器**：应用内「自检」按钮 —— 37 条断言（数据/渲染/交互/打印）。

# A4 文档编辑器（组件化构建）

把一份 A4 文档当成"用组件搭出来的东西"来编辑：左边点组件插入，右边按表单改属性，
中间就是**分页后的真实版面**（所见即所得），最后导出可打印 HTML / PDF。

## 1. 启动

```powershell
D:\Python313\python.exe "E:\可视化编辑器\A4编辑器\启动编辑器.py" -p 8080 -n "D:\Desktop\誉创\金卫项目\方案\方案文件"
```

参数（单字母，只有三个）：

| 参数 | 说明 |
|---|---|
| `-p N` | 端口，默认 8791；被占用时自动往后找 |
| `-n PATH` | 挂载本地 HTML **文件或目录**到 `/m/`，可重复；目录挂成 `/m/<目录名>/…` |
| `-q` | 不自动打开浏览器 |

启动后：编辑器 `http://127.0.0.1:8080/a4_editor.html`；
挂载清单 `http://127.0.0.1:8080/__mounts`；组件清单 `http://127.0.0.1:8080/__components`。
停止：在该窗口按 `Ctrl+C`。

**为什么要起服务**：从 `file://` 直接打开时浏览器禁止 `fetch/XHR` 读本地文件（`<script src>` 不受限，
所以组件仍能加载）；起服务后就没有任何限制，并且可以**加载任意本地文档**：

```
http://127.0.0.1:8080/a4_editor.html?load=/m/方案文件/江苏誉创_金卫智慧舱_主方案_V5.0.html
```

## 2. 界面布局（参照 Qt Designer）

```
┌──────────────────────── 顶栏：加载 / 保存 / 分页预览打印 / 示例 ────────────────────────┐
│ 左：组件选择器（抽屉式）      │ [富文本][源码(MD)][预览] ← 页签固定在顶 │ 右：对象检查器 + 属性编辑器 │
│  · 筛选组件… / 全展开        │ 中：A4 编辑区（分页所见即所得）  │  · 对象检查器（选中了什么） │
│  · 按类别分组：标题/正文/块/图表/版式 │   直接在上面改，停下自动重排      │  · 属性编辑器（属性名 | 值） │
│  · 新建/导入/导出组件        │                              │  · 文档设置（纸张/页边距/页眉页脚）│
│  · 格式与插入（层级/字体/段落/表格/…）│                            │                            │
└──────────────────────────────────────────────────────────────────────────────────┘
```

与 Qt Designer 的对应关系：左侧 **组件选择器** = Widget Box（只放"能插进去的东西"）；
右侧 **对象检查器** = Object Inspector（当前选中元素）、**属性编辑器** = Property Editor（两列表格，改完即时生效）；
**文档设置** 相当于整个窗体的属性。
> **页签（富文本 / 源码(MD) / 预览）固定在中栏顶部**，不再占用左侧面板——左栏就是纯粹的「组件选择器」。
> 旧版把组件库、组件属性、纸张页边距等 11 组全塞在一个 320px 左栏里，选中元素后属性表落在折叠线以下，
> 得自己滚动去找——现在属性编辑器固定在右栏顶部，选中时还会闪烁提示。

## 3. 编辑操作

| 操作 | 怎么做 |
|---|---|
| 插入组件 | 两种方式：① **双击**组件卡片 ② 把卡片**拖到文档里**（插到落点所在块之后，拖动时落点虚线高亮）。组件一律作为**独立块**插到光标所在块之后（光标在表格里则插到整表之后）。**所有插入都只有这一条代码路径** |
| 调表格列宽 / 行高 | **拖表格竖线**（选中表格后列边界出现蓝色手柄）实时调相邻两列宽度，每列最小 8mm；也可在右栏属性表里填 `列宽 20,50,30` / `行高 8mm` |
| 调图片宽度 | 选中图片后**拖右下角的方块**，按 mm 实时改宽度（15mm ~ 版心宽），底部保持比例 |
| 选中组件 | 组件卡片**单击 = 选中**（卡片高亮，不再直接插入）——与 Qt Designer 一致：先在组件选择器里选，再放到文档里 |
| 找组件 | 组件选择器是**抽屉式分类**（标题/正文/块/图表/版式/通用，可折叠、记住展开状态），上方「筛选组件…」可按名称/key/说明过滤，搜到的分类自动展开；「全展开」一键展开全部 |
| 改属性 | 在中间**点选**一个元素 → **右栏「属性编辑器」** 改，改动即时生效。属性按**分组折叠**（文字内容 → 表格与尺寸 → 样式 → 高级），**常改的排前面**、「高级」默认收起，顶部还有「过滤属性…」框 |
| 找组件 | 组件箱按类别分组（标题/正文/块/图表/版式），也可在「筛选组件…」里打字过滤 |
| 新建组件 | 选中元素 → 「新建组件」→ 起个中文名；存进本地库（localStorage） |
| 导入/导出组件包 | 左侧「加载组件包 / 导出组件目录」；导出是**每个组件一个中文名 .js 文件** |
| 重新分页 | 编辑停顿约 0.65 秒自动重排；也可手动点「分页预览」 |
| 编号 | 插入/删除后点「重排编号」，图/表按章编号（图 X-Y、表 X-Y） |
| 导出 | 「保存 HTML」→ 单文件带内联样式的分页 HTML；「分页预览 / 打印 PDF」即得 A4 PDF |

## 4. 组件文件格式

组件就是一段给 `window.A4_COMPONENTS` 赋值的 JS，**改完刷新编辑器即生效**：

```js
/* 组件：图片 + 图题（图表）—— 可自由编辑本文件；改完刷新编辑器即生效 */
window.A4_COMPONENTS = window.A4_COMPONENTS || {};
window.A4_COMPONENTS["figure"] = {
  "key": "figure",
  "name": "图片 + 图题",          // 组件库按钮上的中文名
  "group": "图表",                // 组件库分组
  "match": "div.topo",            // 用来把已有文档里的元素识别回这个组件（可空）
  "html": "<div class=\"topo\">…</div>",   // 插入模板
  "props": [                      // 选中该组件后右侧显示的表单（数据驱动）
    { "k": "src",  "t": "text", "label": "图片地址" },
    { "k": "cap",  "t": "text", "label": "图题" },
    { "k": "imgw", "t": "text", "label": "图宽(如 120mm)" }
  ]
};
```

`props[].t` 支持：`text`（单行）、`area`（多行）、`select`（需带 `opts: [...]`）、
`color`、`number`、`bool`（复选框）。

`props[].k` 是**属性词汇表**（不在这张表里的键名不会生效）：

| k | 作用 |
|---|---|
| `text` | 元素内容（`innerHTML`，可用 `<b>` 等简单标签；`<br>` 视为换行） |
| `items` | 列表：一行一条，生成/更新 `<li>` |
| `cap` | 元素内 `.cap` 的图题/表题文字 |
| `src` | 元素内 `<img>` 的地址 |
| `imgw` | 元素内 `<img>` 的宽度（如 `120mm`） |
| `rows` / `cols` | 表格增删行数 / 列数 |
| `head` | 表格有无表头（布尔） |
| `width` | 表格或元素宽度 |
| `css:<属性>` | 写内联样式，例如 `css:text-align`、`css:font-size`、`css:color` |
| `attr:<属性>` | 写 HTML 属性，例如 `attr:src` |

首页不显示页码、保留原分页、插入页码），不是元素属性——元素属性只在你点选标题/段落/表格/图片后出现。

### 表格的列宽与行高怎么调

两条路，改完自动重排：

1. **属性编辑器**（推荐）：点选表格 → 右栏「属性编辑器 · 表格」→
   - `列宽(如 20%,50%,30%)`：按列填，逗号分隔；**纯数字按百分比**（`20,50,30` → 20%/50%/30%），也可写 `35mm`；
   - `行高(如 8mm)`：所有行（含表头）的最小高度，纯数字按毫米。
   字段里显示的是表格当前的 **colgroup 真实列宽**（例如示例表读回来是 `18%,52%,30%`）。
2. **工具栏**：左侧「格式与插入 → 表格」组里的「列宽 20,50,30」「行高 8mm」两个输入框，
   光标在表格里（或选中表格）即可生效，另有「列宽自适应」按内容重算。

**两种调宽方式都可以**：① 属性编辑器里填（推荐，跨页表格只能用这个）；② 选中表格后**拖表格竖线**实时调相邻两列宽度（每列最小 8mm）——见 §3 与 §8 的自测 ⑱（第 1 列 277→317px）。

### 组件箱的缩略图

组件箱每张卡片都会把该组件的**模板真渲染一份缩略图**（不是图标），所以一眼能看出"图表是网格、提示框是绿边、
封面是分节页"。模板为空的组件（表格/图片/图题由插入函数现场生成）显示占位卡片。

## 5. 自测与调试开关

在 URL 后面加参数（可与 `?load=` 组合）：

| 开关 | 作用 | 最近一次验证 |
|---|---|---|
| `?selftest=1` | 组件层自测 37 条：启动即分页、43 个组件加载与模板自洽、属性读写、表格增删列、**列宽/行高（属性表 + 拖拽手柄）**、**图片宽度拖拽手柄**、**缩略图**、**抽屉式分类**、**单击=选中/双击插入/拖动插入**、**属性分组 + 过滤框**、**插入路径已统一**、A4 纵横向版心、组件包导入、导出 HTML、三段式页码、自测后文档还原（全部用真实鼠标/输入事件断言） | **37/37 全部通过** |
| `?comptest=1` | 把所有组件模板依次排一遍，人工看分页与三节编号 | 未复核（自测已覆盖其编号断言） |
| `?mdtest=1` | Markdown 往返（需与 `?load=` 同用） | **不无损**：152 块 → 151，丢失 1 个 `DIV.note`（Markdown 表达不了，已知局限） |
| `?debug=1` | 把版面测量报告打到浏览器控制台 | 未复核输出内容 |
| `?ori=portrait\|landscape` | 指定纸张方向（覆盖源文件里的方向） | 通过（版心数值已被 `?selftest=1` 断言） |
| `?load=<url\|路径>` | 直接打开一份已生成的 HTML，合并成可编辑流 | 通过（HTTP 挂载下源 18 sheet → 编辑器 18 页，页脚页码序列逐页一致） |

浏览器控制台里 `a4` 前缀的日志与 `SELFTEST_REPORT` 可用于排查。

## 6. 编辑器内建的 A4 排版规范

## 7. 已知限制

- 从 `file://` 打开时不能用 `?load=` 加载本地文件（浏览器限制），组件仍可加载；要加载本地文档请用启动器。
- 「挂载文件」下拉选择器尚未做——目前通过在 URL 上手写 `?load=/m/<名字>/…` 打开挂载文档。
- `?selftest=1` 会临时改动文档内容做断言，结束时恢复；其间会往本地组件库写入一个测试组件并立即删除。
- 组件属性表单是 `k` 词汇表驱动的：自定义新组件时若用了表外的 `k`，表单不会写回。
- 手柄只在**一页之内**的表格/图片上出现（跨页表格请用属性表输入列宽）。

### 这类工具还能做到什么（"富文本"不等于做不到可视化设计）

富文本（contenteditable）+ A4 流式排版是**刻意选择**：文档必须能重排、能分页、能打印、
且与 Word 产线的排版规则一致。它挡住的只有一类功能：

| 能做到，只是还没做 | 说明 |
|---|---|
| 行高拖拽 | 列宽已可拖；行高目前仍是属性表输入（拖行分隔线可照同一套做法加） |
| 撤销 / 重做栈 | 富文本天然支持 `document.execCommand` 的历史，也可以自己记快照 |
| 组件模板库 / 派生 | 现在已有「新建组件」，可再做成"从选中元素派生 + 分类管理" |
| 多选与对齐工具 | 选中元素后做左对齐/居中/等宽等块级操作 |
| 属性网格补齐 | 把字号/行高/颜色/缩进等做成完整的两列表格（现在按组件声明字段） |

| **不适合**在富文本上硬加 | 原因 |
|---|---|
| 自由绝对定位画布（元素任意 x/y/w/h 摆放，web 组态那种） | 会破坏 A4 流式重排、自动分页、页脚页码与打印/Word 一致性 |

> 如果最终目标是"像 web 组态那样在画布上摆控件"，正确的做法是**另做一个画布模式**：
> 元素带 x/y/w/h，编辑时按画布渲染，导出时再按 A4 分页成文档；两条模式共用同一套组件定义与排版令牌，
> 而不是把绝对定位塞进现在这套流式排版里。

## 9. 左侧面板其实是三块东西（别混）

| 位置 | 是什么 | 和组件库的关系 |
|---|---|---|
| 最上「组件箱」+ 筛选框 | **组件库**：43 个结构化模板，按分组抽屉展示 | 这是"内容"的正门：插入后能被 `match` 认领 → 有属性表 → 能重排编号 → 能「新建组件」派生 → 能导出/导入组件包 |
| 中间 6 个按钮（新建组件 / 导出组件包 / 加载组件包 / 选择组件目录 / 导出组件目录 / 清空自建） | **组件库自身的增删导入导出**，不往文档里插内容 | 作用对象是组件库，不是文档 |
| 下半「格式与插入」 | 编辑器最早的**富文本工具条**：层级、字体、段落、表格、列表/块、插入 | 见下 |

「格式与插入」里六组各是什么：

- **层级**：把光标所在块在 正文 ↔ 四级 ↔ 三级 ↔ 二级 ↔ 一级 之间转换（快捷键 `Ctrl+Alt+←/→`）。
  ⚠ 换层级会改变元素被哪个组件认领（`p` → `h2` 就是从"正文段落"变成"章节标题"）。
- **字体 / 段落**：字号、字体、颜色、加粗/斜体/下划线、对齐、行距、首行缩进——**纯格式化**，作用于选中元素或光标所在段落；组件箱里没有对应物（也不该有）。
- **表格**：插入表格（弹窗选行列）、+行/−行/+列/−列、表题、列宽自适应、列宽/行高输入——前几个是"编辑选中的表格"，不是插入新内容。
- **列表 / 块**：• 列表、1. 列表（把**选中的几行**转成列表，不是插入新块）、提示框、示意框、图文框。
- **插入**：图片（走文件对话框）、图题（插到选中图片下方）、分页、分隔线、重排编号（动作）。

**重复但不等价的地方（重点）**：

| 工具条按钮 | 组件箱里的组件 | 关系 |
|---|---|---|
| 提示框 / 示意框 | 提示框 / 示意框 | 产出**同一个** `<div class="note">` / `div.flow`，都会被组件认领——纯重复入口 |
| • 列表 / 1. 列表 | 项目符号列表 / 编号列表 | 不等价：工具条是"把选中行转成列表"，组件箱是"插入一个新列表" |
| 插入（表格弹窗） | 表格 | 组件箱插 2×2 默认表；弹窗能选行列/表头，是超集 |
| 图片（文件对话框） | 图片（填地址） | 入口不同，产出相同 |
| 分页 | 分页符 | 原先**不等价**：工具条插的是 `<hr page-break-after>`，分页引擎只认 `.pgbreak` → 不换页。**已修**：现在两者都走分页符组件 |
| 图题 | 图题 | 原先 `div.figcap` **没有组件认领**，属性表是空的。**已修**：新增「图题」组件 |
| 层级下拉里的「导语」 | 导语 | 原先 `p.lead` 同样无人认领。**已修**：新增「导语」组件 |

## 10. 模块划分与设计约定

主程序原先是一个 1,820 行的单文件（HTML+CSS+一个内联 `<script>`），现已按功能块拆到 `js/` 下 20 个文件。

| 约定 | 说明 |
|---|---|
| 用传统 `<script src>`，不用 ES module | `file://` 下 module 会被 CORS 拦，`<script src>` 不受限——与「组件/」目录同一套加载方式，双击打开和 HTTP 启动都能跑 |
| 文件名数字前缀 = 加载顺序 | `00`→`99`；`99-boot.js` 必须最后，`90-toolbar.js` 只做事件绑定、不承载业务逻辑 |
| 一个文件一个职责 | 例如分页只改 `70-pagination.js`，属性表字段类型只改 `50-props.js`，插入位置规则只改 `46-insert.js` |
| 函数保持普通函数声明 | 跨文件靠加载顺序共享全局作用域，不引入框架、不打包 |
| 依赖方向单向 | 各文件头的「依赖 / 对外」两行是**按实际调用核对过**的；底层不反向依赖上层 |
| 无循环依赖 | 原先 `70-pagination` 的 `reflowSoon` 要调 `80-io` 的 `save`，而 `80` 又依赖 `70` → 已把 `save` 收进 `70-pagination.js` |
| 样式只有一份 | 导出 HTML 的样式由 `80-io` 的 `docCssText()` **从编辑器样式表里自动抽取** `.doc` 规则（去掉前缀）——给组件加样式只需写在 `a4_editor.html` 一处，导出的 PDF 一定跟着变 |
| 重构不改行为 | 拆分后 `?selftest=1` 仍 **24/24**，界面截图与拆分前 **SHA256 完全相同**（逐像素一致） |
| 可单独语法检查 | 每个文件都能 `node --check js/xx.js`，不需要构建工具 |

改功能时的落点：分页/光标 → `70`；属性字段 → `50` + 组件的 `props`；新组件 → 只在 `组件/` 加一个 .js；
界面 → `a4_editor.html` 的 HTML/CSS；新按钮 → `90-toolbar.js` 绑定 + 对应模块加函数。

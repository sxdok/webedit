feat(web-editor): 输出「组件功能属性 + 属性编辑器状态」说明清单（从注册表生成）

清单内容（每个组件一段，回答用户的两个问题）：
1) 它有哪些功能属性：逐项列出 面板显示名 / key / 控件 / 排版（单行式 or 整行式）/ 默认值 / 说明与取值
   （单位、范围、可选项、是否按条件显示、是否通用属性）
2) 选中它之后属性编辑器是什么状态：面板分组与各组项数、哪个组默认展开、「单元格」组何时自动展开、
   顶部固定区（组件名/type 徽标/ID/过滤框）、Web 模式额外块（位置与尺寸）、容器专属块（子组件列表）、
   该组件用到的全部控件

为什么从注册表生成：手写清单必然与代码漂移（这轮就踩到 README 写"15 种控件"实际 14）。
生成器直接读注册表 + 面板常量（GROUP_ORDER / DEFAULT_OPEN_GROUP / isWideControl），加删组件后重新生成即可。

落盘与入口：
- 启动器新增 POST /__save（只允许写运行目录 docs/ 下，越界返回 403）
- 菜单「帮助 → 导出组件与属性说明清单」或 ?spec=1
- 产物 web-editor/docs/组件与属性说明清单.md（137465 字节 / 2695 行，48 个组件全覆盖）
- 无 /__save 接口（file:// 或别的静态服务器）时退回下载

修掉清单暴露出的真实回归：
- 默认展开组改成「表格」后，不含「表格」组的非表格组件会全部折叠（选中后看不到任何属性）
  → 改为"有表格组展开表格组，否则展开第一个组"，并补断言「非表格组件也有默认展开的分组」
- 清单自身两个 Markdown 缺陷：单元格内容里的 | 未转义会撑破表格；嵌套粗体导致标题破损
